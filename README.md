# Practice Mark for YouTube — Quick Start

Practice Mark turns a YouTube lesson into a hands-free practice workstation. Mark useful moments while the video keeps playing, automatically turn pairs of marks into loops, replay them, slow them down, and control practice by voice.

## Start in 60 seconds

1. Open a YouTube lesson or practice video.
2. Open the Practice Mark panel if it is hidden, then click **🎙 Listen** under **START HERE**. Chrome may ask for microphone access.
3. Keep watching and say **“mark that”** whenever you want to save a point. **M1 + M2 = Loop 1**, **M3 + M4 = Loop 2**, and so on.
4. Click **Practice** on any loop, or say **“play loop one.”**
5. Use the loop **− / +** buttons, or say **“slower / slow down”** and **“faster / speed up.”**
6. Say **“pause,” “wait,” or “hold on”** to pause; **“play”** to continue; **“again”** to restart the active loop; and **“stop looping”** to leave loop mode.

## Useful controls

| What you want | Voice command |
| --- | --- |
| Save a point | “mark that” |
| Pause | “pause” · “wait” · “hold on” |
| Resume | “play” |
| Practice a loop | “play loop one” |
| Restart the active loop | “again” · “repeat that” |
| Slow down | “slower” · “slow down” |
| Speed up | “faster” · “speed up” |
| Stop looping | “stop looping” |

Rename a loop to something memorable such as **Chorus** and then say **“play chorus,” “chorus again,”** or **“chorus slow down.”** You can also change a loop’s Start/End dropdowns or drag marks onto them.

## A few tips

- Voice works best when your voice is clearer than the YouTube audio; headphones help when an instructor is talking continuously.
- Voice listening is **off until you click Listen**. This is intentional so microphone use is always explicit.
- Practice Mark stores marks and loops locally in Chrome for each YouTube video.
- Practice Mark does **not** record audio. Voice commands use Chrome’s built-in speech recognition. See `PRIVACY.md` for details.
- If voice behaves strangely, open **Diagnostics → Export voice diagnostics** before refreshing the page and attach the JSON to a support issue.
