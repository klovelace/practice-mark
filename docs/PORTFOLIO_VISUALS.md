# Practice Mark portfolio visual capture

**Goal:** Show the real extension in use, with screenshots next to short product explanations. Capture from the current verified build, not a mockup.

## Capture checklist

1. **Hero image — the product in context.** Open a public YouTube lesson with the Practice Mark panel visible. Create two marks and show the resulting loop. Crop to include the video player and panel. Avoid personal accounts, private tabs and identifying browser information.
2. **Loop workflow — an actual interaction.** Capture the panel with at least two named loops and an active loop selection. Use a video you are authorized to display in a screenshot, or crop the third-party video content out.
3. **Hands-free controls — optional voice mode.** Capture the listening control only after opting in. Do not imply speech recognition is a proprietary model.
4. **Privacy/permissions — optional supporting frame.** Show the extension's own interface or permissions disclosure without exposing private browsing information.

## Image specification

- Capture PNG at a browser viewport around 1440×900 or 1600×900; use 100–125% zoom if the panel text is too small.
- Crop tightly around the interaction; keep text readable at approximately 650–850 px displayed width.
- Prefer 16:9 for the hero and 4:3 for detailed UI.
- Save reviewed files as `docs/assets/practice-mark-hero.png`, `docs/assets/practice-mark-loops.png` and optionally `docs/assets/practice-mark-voice.png`.
- Add descriptive alt text, not labels such as “screenshot 1.”

## Suggested captions

**Practice Mark in use:** Mark moments in a YouTube lesson, convert pairs of marks into loops, and replay difficult passages without repeatedly scrubbing the timeline.

**Loop controls:** Save, select, rename and replay practice segments while keeping playback speed under your control.

**Optional voice input:** Issue hands-free commands while practicing; speech recognition relies on browser services.

## Publication review

Confirm screenshots match the published beta version, do not display copyrighted video material beyond appropriate incidental context, and contain no sensitive data. Run the manual QA checklist before claiming the captured workflow was verified. Do not add an unverified Chrome Web Store link.

## README placement

Once screenshots are uploaded, place the hero image beside the “user workflow” summary in a two-column HTML table, matching the GitHub profile's visual-left/text-right treatment. Put additional screenshots below as an image strip or short walkthrough. Never add image references before the files exist.
